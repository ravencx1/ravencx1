This project contain 7455 participantswith body measures and accelerometer data
data stored in .txt format
in each file, the first line contains participant id
Second line is data header.
from third line to the end is the data.

Header columns:
     1  "PAXSTAT"
     2  "PAXCAL"
     3  "PAXDAY"
     4  "PAXN"
     5  "PAXHOUR"
     6  "PAXMINUT"
     7  "PAXINTEN"
     8  "PAXSTEP"
